# API для Заметок (Notes API)

Простой, но функциональный REST API для управления заметками. Проект создан в
образовательных целях для изучения основ бэкенд-разработки на стеке Node.js.

## ✨ Возможности

- **CRUD операции:** Полная поддержка создания, чтения, обновления и удаления
  заметок.
- **База данных:** PostgreSQL, работающая в изолированном Docker-контейнере.
- **ORM:** Prisma для удобного и безопасного взаимодействия с базой данных.
- **Архитектура:** Чистая трёхслойная архитектура (Routes → Controllers →
  Services).
- **Обработка ошибок:** Централизованная обработка асинхронных ошибок.
- **Конфигурация:** Безопасное управление конфигурацией через переменные
  окружения (`.env`).

## 🚀 Установка и запуск

Для запуска проекта на локальной машине выполните следующие шаги.

### Требования

- [Node.js](https://nodejs.org/en/download/) (рекомендуется версия 18.x или
  выше)
- [pnpm](https://pnpm.io/installation)
- [Docker Desktop](https://www.docker.com/products/docker-desktop/)

### Пошаговая инструкция

1. **Клонируйте репозиторий:**
   ```bash
	 git clone <ссылка_на_ваш_репозиторий>
	 cd <название_папки_проекта>
	 ```

2. **Установите зависимости:**
   ```bash
	 pnpm install
	 ```

3. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта, скопировав содержимое из
   `.env.example`. Значения по умолчанию уже подходят для локальной разработки.
   ```bash
	 cp .env.example .env
	 ```

4. **Запустите базу данных в Docker:**
   Эта команда создаст и запустит контейнер с PostgreSQL в фоновом режиме.
   ```bash
	 docker-compose up -d
	 ```

5. **Примените миграции базы данных:**
   Эта команда создаст таблицы в вашей базе данных в соответствии со схемой
   Prisma.
   ```bash
	 pnpm prisma migrate dev
	 ```

6. **Запустите приложение в режиме разработки:**
   Сервер запустится с автоматическим перезапуском при изменениях в коде.
   ```bash
	 pnpm run dev
	 ```

🎉 После этого приложение будет доступно по адресу `http://localhost:3000`.

## 📖 API Эндпоинты

| Метод    | Путь         | Описание                       | Тело запроса (пример)                          |
|:---------|:-------------|:-------------------------------|:-----------------------------------------------|
| `GET`    | `/notes`     | Получить список всех заметок   | -                                              |
| `GET`    | `/notes/:id` | Получить одну заметку по ID    | -                                              |
| `POST`   | `/notes`     | Создать новую заметку          | `{ "title": "Новая", "content": "Текст" }`     |
| `PUT`    | `/notes/:id` | **Полностью** обновить заметку | `{ "title": "Обновлено", "content": "Новый" }` |
| `PATCH`  | `/notes/:id` | **Частично** обновить заметку  | `{ "title": "Только заголовок" }`              |
| `DELETE` | `/notes/:id` | Удалить заметку                | -                                              |
| `GET`    | `/health`    | Проверить "здоровье" сервиса   | -                                              |
